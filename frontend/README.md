# Avtoplaneta Frontend - Веб-приложение для управления автозапчастями

## Описание проекта

Это веб-приложение на React + TypeScript для управления инвентарем автозапчастей. Приложение предоставляет интерфейс для администраторов, менеджеров и операторов для работы с запасами, заказами и пользователями системы.

## Основные возможности

- **Управление инвентарем**: Просмотр, добавление, редактирование и удаление автозапчастей
- **Управление заказами**: Создание и отслеживание заказов с цветовой кодировкой статусов
- **Аутентификация пользователей**: Вход через локальную систему или Google OAuth
- **Ролевая система**: Разные уровни доступа (Admin, Manager, Operator)
- **Загрузка изображений**: Drag & drop загрузка фотографий запчастей
- **Поиск и фильтрация**: Полнотекстовый поиск с Elasticsearch интеграцией
- **Админ-панель**: Управление пользователями и просмотр системных логов

## Технологии

- **React 18** с TypeScript
- **Vite** для сборки и разработки
- **React Query** для управления состоянием API
- **React Router** для навигации
- **Tailwind CSS** для стилизации
- **Shadcn/ui** компоненты
- **React Hook Form** для форм
- **Axios** для HTTP запросов

## Запуск проекта

### Требования
- Node.js 18+
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

### Сборка для продакшена
```bash
npm run build
```

### Предпросмотр сборки
```bash
npm run preview
```

## Конфигурация

### Переменные окружения
Создайте файл `.env` в корне frontend директории:

```env
VITE_API_BASE_URL=http://localhost:8080
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

### ESLint конфигурация

Проект использует современную конфигурацию ESLint с поддержкой TypeScript. Для продакшена рекомендуется включить type-aware правила:

```js
// eslint.config.js
export default defineConfig([
  // ... существующая конфигурация
  {
    files: ['**/*.{ts,tsx}'],
    extends: [
      tseslint.configs.recommendedTypeChecked,
      // или tseslint.configs.strictTypeChecked для строгих правил
    ],
    languageOptions: {
      parserOptions: {
        project: ['./tsconfig.node.json', './tsconfig.app.json'],
      },
    },
  },
])
```

## API интеграция

Приложение взаимодействует с микросервисами backend:
- **API Gateway**: `http://localhost:8080` - основной шлюз
- **Auth Service**: `/auth/*` - аутентификация
- **Parts Service**: `/api/inventory/*` - управление запчастями
- **Orders Service**: `/orders/*` - управление заказами

## Безопасность

- **CSRF защита**: Все запросы включают CSRF токены
- **CORS**: Настроен для локальной разработки
- **Ролевая авторизация**: Middleware проверяет права доступа
- **Валидация данных**: На клиенте и сервере
