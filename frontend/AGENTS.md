# Стандарты разработки Frontend Avtoplaneta (frontend/AGENTS.md)

Данный документ содержит обязательные правила разработки клиентской веб-части **Avtoplaneta** (React 19, TypeScript, Vite, Tailwind CSS v4, TanStack Query v5).

---

## 1. Производительность и метрики Core Web Vitals
- **INP (Interaction to Next Paint):** Целевое значение **< 200ms**. Любые тяжелые вычисления, парсинг больших JSON или фильтрация каталога не должны блокировать основной поток UI.
- **Debounced поиск:** Все поля ввода поиска обязаны использовать debounce (250–300ms) для исключения спама запросами в бэкенд.
- **Параллельная загрузка изображений:** Изображения в карточках деталей и галереях загружаются параллельно (`Promise.all` / `loading="lazy"`), а не последовательно.

---

## 2. Управление состоянием и сервером (TanStack Query v5)
- **Инвалидация кэша:** После любых мутаций (`useMutation`) обязательно инвалидировать связанные query-ключи:
  ```ts
  queryClient.invalidateQueries({ queryKey: ['inventory'] });
  queryClient.invalidateQueries({ queryKey: ['parts', partId] });
  ```
- **Оптимистичные обновления:** Для быстрых переключателей (смена статуса, избранное) использовать optimistic updates с откатом при ошибке.
- **ETag / Кэширование:** Клиент отправляет заголовки `If-None-Match`, корректно обрабатывая ответы `304 Not Modified`.

---

## 3. Контракты API и типы
- **Синхронизация спецификации:** Спецификация API синхронизируется в `frontend/src/data/swagger.json` по команде `make proto` из каталога `backend/`.
- **Типизация:** Все DTO запросов и ответов должны быть строго типизированы в TypeScript без использования типа `any`.
- **Маршрутизация API:** Все вызовы API идут через единый Traefik API Gateway (`/api/v1/*` для gRPC-Gateway и `/api/*` для нативного REST).

---

## 4. UI компоненты и стили
- Стилизация осуществляется строго через **Tailwind CSS v4**.
