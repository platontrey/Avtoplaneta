# Интеграция с классифайдом Drom.ru (YML Каталог)

Данный документ описывает архитектуру, формат данных, сетевой транспорт и правила валидации для автоматической выгрузки каталога автозапчастей компании **«Автопланета»** на площадку **Drom.ru**.

---

## 1. Архитектура и сетевой транспорт

```
   ┌──────────────────────────────────────────────────────────────┐
   │                          DROM.RU                             │
   │               (Автоматический робот-парсер)                  │
   └──────────────────────────────┬───────────────────────────────┘
                                  │ GET /uploads/pricelist.xml (HTTP порт 80)
                                  ▼
   ┌──────────────────────────────────────────────────────────────┐
   │                       Traefik 3.x                            │
   │            (Точка входа :80, роутер без HTTPS)               │
   └──────────────────────────────┬───────────────────────────────┘
                                  │ /uploads/pricelist.xml
                                  ▼
   ┌──────────────────────────────────────────────────────────────┐
   │                     export-service (:8085)                   │
   │  ┌─────────────────────────┐  ┌───────────────────────────┐  │
   │  │   bbolt (catalog.db)    │  │     pricelist.xml         │  │
   │  │  (Инкрементальный кэш)  │  │  (Потоковый YML срез)     │  │
   │  └─────────────────────────┘  └───────────────────────────┘  │
   └──────────────▲───────────────────────────────▲───────────────┘
                  │ gRPC ListPartsForExport       │ Redis Streams
                  │                               │ parts:stock_events
   ┌──────────────┴─────────────┐  ┌──────────────┴───────────────┐
   │       parts-service        │  │         auth-service         │
   │     (PostgreSQL/Catalog)   │  │       (ИНН продавцов)        │
   └────────────────────────────┘  └──────────────────────────────┘
```

### 1.1. Транспортные требования Drom
1. **Протокол:** Строго чистый HTTP (порт 80). Робот Drom не поддерживает TLS/HTTPS при считывании ссылки прайс-листа и завершает выгрузку ошибкой при 301/302 Redirect.
2. **Публичный URL:** `http://backend-server.ru/uploads/pricelist.xml`.
3. **Маршрутизация Traefik:** 
   - На точке входа `web` (порт 80) настроен приоритетный роутер `export-pricelist-http` (priority 1000), направляющий запросы напрямую в контейнер `export-service`.
   - Общий редирект на HTTPS для остальных адресов сайта действует с низким приоритетом (priority 1).

## 2. Формат данных: Канонический YML (Yandex Market Language)

Drom использует профиль импорта YML каталога с DTD схемой `shops.dtd`. Изменение структуры корневых тегов приводит к заморозке фида и отправке на ручную модерацию.

### 2.1. Корневая структура документа
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE yml_catalog SYSTEM "shops.dtd">
<yml_catalog date="2026-10-27 13:50">
  <shop>
    <name>АВТОПЛАНЕТА</name>
    <company>АВТОПЛАНЕТА</company>
    <url>http://backend-server.ru/</url>
    <platform>Avtoplaneta</platform>
    <email>Planeta.zap@mail.ru</email>
    <currencies>
      <currency id="РУБ" rate="1"/>
    </currencies>
    <categories>
      <category id="1">Автозапчасти</category>
    </categories>
    <offers>
      <!-- Товарные предложения <offer> -->
    </offers>
  </shop>
</yml_catalog>
```

### 2.2. Требования к валюте и категориям
- **Валюта:** Идентификатор валюты строго `РУБ` с курсом `rate="1"` (соответствует историческому профилю Drom).
- **Категории:** Рубрикация на Drom выполняется полностью автоматически собственной нейросетью/лемматизатором площадки на базе `<name>` и `<param name="...">`. По стандарту YML достаточно указать базовую категорию `<category id="1">Автозапчасти</category>`, и каждый оффер ссылается на `<categoryId>1</categoryId>`.

## 3. Товарное предложение (`<offer>`): Таблица параметров

### 3.1. Структура оффера
```xml
<offer id="40282" available="true" bid="3">
  <url>http://backend-server.ru/parts/40282</url>
  <price>18500.50</price>
  <currencyId>РУБ</currencyId>
  <categoryId>1</categoryId>
  <picture>http://backend-server.ru/uploads/parts/1.jpg</picture>
  <picture>http://backend-server.ru/uploads/parts/2.jpg</picture>
  <store>true</store>
  <pickup>true</pickup>
  <delivery>true</delivery>
  <name>Фара правая светодиодная</name>
  <description><![CDATA[Оригинал в отличном состоянии, все крепления целые]]></description>
  <sales_notes>Способ оплаты уточняйте по телефону</sales_notes>
  <barcode>40282</barcode>
  <cpa>1</cpa>
  <param name="Марка автомобиля">Toyota</param>
  <param name="Модель автомобиля">Camry</param>
  <param name="Марка кузова">XV70</param>
  <param name="Марка двигателя">2AR-FE</param>
  <param name="Дата выпуска автомобиля">2019</param>
  <param name="Перед/зад">перед</param>
  <param name="Право/лево">право</param>
  <param name="Б/у или новый(-ая)">Б/у</param>
  <param name="Трансмиссия">АКПП</param>
  <param name="Расположение">Склад №2, ряд 4, полка 12</param>
  <param name="ИНН поставщика">7017123456</param>
  <param name="ОЕМ код">81110-33D30</param>
  <param name="Код производителя">AP-778899</param>
</offer>
```

### 3.2. Маппинг атрибутов и параметров

| Поле в YML | Поле в БД / Proto | Описание и бизнес-правило |
| :--- | :--- | :--- |
| `id` (attr) | `part.id` | Уникальный 64-битный первичный ключ запчасти |
| `available` (attr) | `part.status && quantity >= 1` | `true` для доступных к продаже деталей |
| `bid` (attr) | `"3"` | Ставка клика CPC для приоритетного размещения |
| `<price>` | `part.price` | Розничная цена (поддерживает цену `0`) |
| `<currencyId>` | `"РУБ"` | Код валюты |
| `<picture>` | `part.photos` | Абсолютный URL к каждой фотографии детали |
| `<name>` | `part.name` | Нормализованное наименование (исправление опечаток лемматизатора) |
| `<description>` | `part.description` | Текстовое описание в CDATA блоке |
| `Марка автомобиля` | `part.brand` | Бренд авто (например, `Toyota`, `Nissan`) |
| `Модель автомобиля` | `part.model` | Модель авто (например, `Camry`, `X-Trail`) |
| `Марка кузова` | `part.body_brand` | **Только поколение/шасси** (например, `XV70`, `S50`, `NZE121`) |
| `Марка двигателя` | `part.engine_brand` | Модель ДВС (например, `2AR-FE`, `1NZ-FE`) |
| `Дата выпуска автомобиля`| `part.car_release_date` | Год выпуска авто |
| `Перед/зад` | `part.front_rear` | Расположение по оси (`перед`, `зад`) |
| `Право/лево` | `part.left_right` | Сторона установки (`право`, `лево`) |
| `Б/у или новый(-ая)` | `part.condition` | Состояние (`Б/у` по умолчанию, если пусто) |
| `Трансмиссия` | `part.transmission` | Тип КПП (`АКПП`, `МКПП`, `Вариатор`) |
| `Расположение` | `part.location` | Склад/полка или адрес точки выдачи |
| `ОЕМ код` | `part.oem_code` | Оригинальный артикул завода-изготовителя |
| `Код производителя` | `part.supplier_code` | Внутренний складской артикул продавца |
| `Состояние/дефект` | `part.defect` | Описание дефекта (если есть) |
| `Процент износа` | `part.wear_percentage` | Процент износа детали |

## 4. Строгий запрет на VIN и серийный номер кузова (Data Security Rule)

> [!CAUTION]
> **Критическое бизнес-правило:**
> В выгрузку **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** включать VIN-номера и серийные номера кузовов (Frame).
> 
> - Тег `<vin>` **никогда не генерируется**.
> - Параметры `<param name="VIN">` и `<param name="Номер кузова">` **запрещены**.
> - Разрешен исключительно параметр `<param name="Марка кузова">`, содержащий модельный код поколения автомобиля (например, `XV70`, `E38`, `NZE121`).
> 
> Запрет гарантирован автоматическим тестом: `TestGenerateXMLPriceListStrictlyExcludesVINAndFrameNumber`.

## 5. Параметры шин и дисков

Для шин и колесных дисков формируются специализированные параметры YML:

| Параметр в YML | Поле в БД | Пример значения |
| :--- | :--- | :--- |
| `Диаметр` | `part.diameter` | `17` (префикс "R" автоматически удаляется) |
| `Ширина` | `part.width` | `235` (для шин) / `7.5` (для дисков) |
| `Профиль` | `part.profile` | `65` (высота профиля шины в %) |
| `Сезон` | `part.season` | `Зимняя`, `Летняя`, `Всесезонная` |
| `Модель шины` | `part.tire_model`| `Michelin X-Ice North` |
| `Сверловка` | `part.drilling` | `5x114.3` (разделители `/` и `*` нормализуются в `x`) |
| `Вылет` | `part.offset` | `45` (ET вылет диска) |
| `Диаметр ЦО` | `part.center_hole_diameter` | `67.1` (DIA центрального отверстия) |
| `Количество` | `part.tire_quantity` | `4` (комплектность) |

## 6. Производительность: Слепок bbolt и потоковая запись

- Каталог содержит десятки тысяч позиций. Для исключения пиковой нагрузки на PostgreSQL и сеть, `export-service` хранит локальный слепок в базе `bbolt` (`/uploads/catalog.db`).
- **Сборка XML (`WriteFullXML`):** Выполняется потоково через буферизованный I/O (`bufio.WriterSize 64KB`).
- **Бенчмарк:** Запись 1000 офферов занимает **370 микросекунд** с 22 аллокациями памяти. Полный каталог на 50 000 позиций генерируется быстрее 20 мс.
