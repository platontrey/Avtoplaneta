# Vehicle catalog

`vehicles.json` — справочник марок и моделей автомобилей. Это единственный
источник выпадающих списков «Бренд» и «Модель»: и веб, и мобильное приложение
получают его одним ответом `GET /api/vehicle-catalog`, поэтому списка марок
не должно быть ни в TypeScript, ни в Dart.

## Чем отличается от catalog.json

| | `catalog/catalog.json` | `vehicles/vehicles.json` |
|---|---|---|
| Кто меняет | человек | команда `make vehicle-catalog` |
| Что описывает | поля форм и шаблоны дефектовки | марки и модели автомобилей |
| Версия | ставится руками | дата + отпечаток содержимого |

Справочники разделены сознательно: у них разный жизненный цикл, и обновление
марок не должно сбрасывать клиентский кэш каталога запчастей (678 КБ) — у
каждого свой ETag.

## Как обновить

```sh
cd backend && make vehicle-catalog
```

Команда обходит `https://www.drom.ru/catalog/` и страницы марок, перезаписывает
этот файл и прогоняет тесты справочника. Между запросами держится пауза в одну
секунду — столько объявлено в `robots.txt` drom.ru; сам раздел `/catalog/` там
не запрещён. Прогон занимает несколько минут.

Версия считается как дата плюс отпечаток содержимого, поэтому повторный запуск
без изменений на сайте не меняет ни версию, ни ETag, и клиенты ничего не
перекачивают. Дифф файла перед коммитом стоит просмотреть: заметное падение
числа моделей означает, что на сайте поменялась разметка.

## Формат

```json
{
  "version": "2026-09-17.ab12cd34",
  "source": "https://www.drom.ru/catalog/",
  "generated_at": "2026-09-17T07:00:00Z",
  "brands": [
    { "name": "Toyota", "slug": "toyota",
      "models": [ { "name": "Camry", "slug": "camry" } ] }
  ]
}
```

Марки и модели отсортированы по имени без учёта регистра — это проверяется в
`validateVehicleCatalog`, чтобы порядок не «плавал» между прогонами и дифф
оставался читаемым.

Поле `slug` нужно парсеру для сопоставления записей между запусками; клиенты
показывают `name`. Марка, которой нет в справочнике, и модель у марки без
моделей вводятся руками — списки подсказывают, но не ограничивают, иначе
редкие машины и спецтехнику стало бы невозможно завести.
