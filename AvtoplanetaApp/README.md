# AvtoplanetaApp - Android Приложение

## Исправленные проблемы

Следующие проблемы были решены в проекте Android Studio:

### 1. Проблемы конфигурации сборки
- **Исправлена ошибка синтаксиса compileSdk**: Изменено с `compileSdk { version = release(36) }` на `compileSdk = 34`
- **Обновлен targetSdk**: Изменено с 36 на 34 для лучшей совместимости
- **Добавлен плагин Kotlin**: Добавлена поддержка Kotlin для функциональности view binding

### 2. Конфигурация Gradle
- **Обновлена версия Gradle**: Изменено с 8.13 на 8.5 для лучшей стабильности
- **Обновлена версия AGP**: Изменено с 8.13.0 на 8.1.4 для совместимости
- **Добавлены зависимости Kotlin**: Добавлена зависимость kotlin-stdlib

### 3. Конфигурация сети
- **Исправлена конечная точка API**: Изменено с порта 8083 на 8080 для соответствия сервисам backend
- **Добавлена конфигурация сетевой безопасности**: Создан `network_security_config.xml` для HTTP трафика
- **Обновлен AndroidManifest**: Добавлена ссылка на конфигурацию сетевой безопасности

### 4. Зависимости
- **Добавлена отсутствующая поддержка Kotlin**: Добавлены kotlin-android plugin и stdlib
- **Обновлен каталог версий**: Добавлена версия Kotlin в libs.versions.toml

## Функции

- **Аутентификация**: Вход с email/именем пользователя и паролем
- **Управление сессиями**: Постоянный вход с использованием SharedPreferences
- **Интеграция API**: HTTP клиент на базе Retrofit для коммуникации с backend
- **Material Design**: Современный UI с компонентами Material Design
- **View Binding**: Безопасное по типам view binding для макетов

## Интеграция с Backend

Приложение подключается к сервисам backend Avtoplaneta:
- **Auth Service**: Порт 8080 для аутентификации
- **Parts Service**: Порт 8081 для управления инвентарем
- **Orders Service**: Порт 8082 для управления заказами

## Запуск проекта

1. Откройте проект в Android Studio
2. Синхронизируйте проект с файлами Gradle
3. Запустите на эмуляторе или физическом устройстве
4. Приложение подключится к `http://10.0.2.2:8080/` (localhost для эмулятора Android)

## Примечания

- Приложение использует HTTP (не HTTPS) для локальной разработки
- Конфигурация сетевой безопасности разрешает cleartext трафик для localhost
- View binding включен для безопасного доступа к view
- Компоненты Material Design 3 используются во всем UI

## Устранение неполадок

Если вы столкнетесь с проблемами Gradle wrapper:
1. Попробуйте запустить `gradlew-fix.bat` вместо `gradlew.bat`
2. Убедитесь, что у вас есть правильные разрешения для домашней директории пользователя Gradle
3. Попробуйте запустить Android Studio от имени администратора, если необходимо
